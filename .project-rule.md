# ZFlow Project Directives
- **Core Principle:** Sovereign Node-based Workflow Engine engineered specifically for LLM Chatbots, Dialog Agents, and Multi-turn Reasoning Pipelines.
- **Backend Architecture:** Asynchronous FastAPI execution engine supporting DAG & Cyclic loops, Server-Sent Events (SSE) token streaming, and dynamic node option binding.
- **Frontend Architecture:** Modern React Flow canvas with custom nodes, real-time edge wiring, parameter inspector, and live streaming chat playground drawer.
- **Communication:** Streaming SSE via `/api/chat/stream` for sub-100ms Time-To-First-Token (TTFT).
